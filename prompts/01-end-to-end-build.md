# Prompt 01 — End-to-End Build: Intelligent Bistro

I am building this for the Viridien AI Full-Stack Engineering Internship challenge.

Build a production-quality full-stack mobile app called Intelligent Bistro.

The goal is to create a polished React Native Expo app with a Node.js backend where an AI assistant manages restaurant ordering through natural language.

I want this to look like something I can confidently demo in a 5-minute Loom video, not just a basic assignment.

Use Expo React Native, TypeScript, Zustand, Node.js, Express, and Zod. Include an LLM-compatible backend service, but also include a deterministic fallback parser so the app works reliably without an API key.

The app needs:

- Futuristic mobile UI
- Restaurant menu
- Cart state management
- AI assistant chat
- Natural language cart updates
- Structured JSON actions
- Backend validation
- README
- Demo commands
- Clean repo structure

Build it like an engineer trying to show speed, taste, reliability, and product thinking.
